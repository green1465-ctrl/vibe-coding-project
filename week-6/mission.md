# Mission

소형·중형 외식 프랜차이즈를 관리하는 영업대행업체는
매월 시즌 캠페인 콘텐츠를 클라이언트별로 만드는 데 시간이 너무 많이 든다.
업종(한식·분식·카페 등)이 달라서 일괄 콘텐츠로는 통하지 않으며,
시즌 트렌드를 수기로 검색·정리하는 작업이 반복적이고 비효율적이다.

이 앱은 매월 1회, 시스템이 4개 외식 트렌드 소스에서 **업종별 트렌드를 자동 수집**하고,
AI가 클라이언트별로 카피를 **재창조한 카드뉴스 5장 세트**(이미지 1 + 텍스트 4)를 생성한다.
사용자는 카피만 수정해 **PNG zip으로 다운로드**하고,
가맹점은 SNS·POP에 그대로 활용할 수 있다.

> Card-news for seasonal franchise menus.

---

## Who
외식 프랜차이즈를 관리하는 영업대행업체 (1인 ~ 소규모)

## Problem
- 매월 시즌 캠페인 콘텐츠를 클라이언트별로 만드는 데 시간 과다
- 업종(한식·분식·카페 등)이 다양해 일괄 콘텐츠로는 통하지 않음
- 시즌 트렌드를 수기 검색·정리하는 작업이 반복적·비효율적
- 가맹점이 그대로 사용할 수 있는 슬라이드 형태로 가공해야 하는 부담

## How
1. 사용자가 클라이언트 5개를 등록 (UI CRUD: 추가/수정/삭제)
2. 매월 1회 **"이번 달 트렌드 가져오기"** 클릭 → 시스템이 4개 소스에서 업종별 트렌드 자동 수집
   - ahatrend.com — 검색량·핫메뉴 순위
   - foodbank.co.kr — 시즌 트렌드 기사
   - atfis.or.kr — 외식산업 통계
   - Google — fallback / 보조
3. 트렌드 컨텍스트 + 클라이언트 정보로 OpenAI gpt-4o-mini가 **카피 5섹션 재창조** (트렌드 원문 X, 가맹점이 그대로 쓸 수 있게 가공)
4. fal.ai Z-Image Turbo로 클라이언트당 **음식 이미지 1장** 생성
5. **슬라이드 5장 합성** (Playwright HTML→PNG)
   - Slide 1: 음식 이미지 + 헤드라인 텍스트 오버레이
   - Slide 2: 시즌 인사이트
   - Slide 3: 추천 메뉴 ①
   - Slide 4: 추천 메뉴 ② 또는 마케팅 포인트
   - Slide 5: CTA + 출처 표시
6. 화면에 5장 carousel 미리보기 + 카피 인라인 수정 (이미지 재생성 X)
7. 카피 수정 시 슬라이드 자동 재합성
8. **PNG 5장 zip 다운로드**

## Platform
반응형 웹앱 (브라우저 동작, 모바일에서도 열림). 네이티브 모바일 앱 X.

## v1 Scope (6주차 완성)
- **클라이언트**: 5개 (CRUD UI)
- **업종**: 외식 프랜차이즈 (한식·분식·카페 카테고리 메타데이터)
- **결과물**: 클라이언트당 슬라이드 5장 PNG (1080×1080 정사각)
  - Slide 1 = fal.ai 이미지 + 헤드라인 오버레이
  - Slide 2~5 = 텍스트 위주 (배경 + 카피)
- **트렌드 수집**: 매월 1회 수동 트리거, 4개 소스
- **출처 표시**: Slide 5에 출처 사이트 명시
- **수정 권한**: 카피만 (이미지 재생성 X)
- **다운로드**: 클라이언트별 PNG 5장 zip

## Out of Scope (v2 이후)
- 클라이언트 30개 확장
- 실제 메일 발송 (v1.5 — Nodemailer + Gmail SMTP)
- 발송 자동 스케줄링
- 이미지 재생성 기능
- 슬라이드 디자인 템플릿 다양화 (현재 v1은 1개 디자인)
- ikfa.or.kr / k-franchise.or.kr 연동 (시즌 트렌드 콘텐츠 부족하다고 판단)
- 네이티브 모바일 앱

## Definition of Done (6주차 마지막 날)
"5월 시즌 캠페인을, 외식 프랜차이즈 5개 클라이언트(예: 한식 2 / 분식 1 / 카페 2) 대상으로,
업종별 트렌드 자동 수집 → 카피 재창조 → 슬라이드 5장 생성 → PNG zip 다운로드까지
한 사이클을 30분 이내에 마친다."

## 기술 스택
- **LLM**: OpenAI gpt-4o-mini (카피 재창조)
- **이미지**: fal.ai Z-Image Turbo (음식 이미지 1장/클라이언트, 장당 약 7원)
- **스크래핑 + 슬라이드 합성**: Playwright (한 라이브러리로 둘 다 처리)
- **PNG zip**: archiver
- **프론트**: React 18 (CDN) + Tailwind (CDN) + Babel standalone
- **백엔드**: Express (단일 single.js)
- **저장소**: data/clients.json + data/campaigns.json + slides/ (PNG 임시)

## 비용 가늠
- 5개 클라이언트 × 음식 이미지 1장 = **35원/사이클**
- LLM 카피 재창조: 클라이언트당 약 1,500 토큰 = 사이클당 수백 원
- 트렌드 스크래핑: 무료 (셀프 호스팅 Playwright)
- **월간 운영 비용: 약 1,000원 미만**
