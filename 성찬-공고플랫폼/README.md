# 공고 스크리닝 대시보드

행정사·가맹거래사사무소 성찬 내부용. 기업마당 공고에서 행정사가 대리·대행할 수 있는
인허가·인증 업무를 자동으로 찾아낸다.

## 쓰는 법

### 1. 공고 수집 (하루 1회 권장)

```
npm run collect
```

기업마당 API에서 공고를 받고, 첨부 PDF의 제출서류까지 읽어 분석한 뒤
`public/data.js` 로 저장한다. 300건 기준 3~5분 걸린다.

### 2. 대시보드 열기

`public/index.html` 을 더블클릭한다. 서버가 필요 없다.

## 왜 PDF까지 읽는가

기업마당 API는 **제출서류를 주지 않는다.** 공고명·사업개요·지원대상만 준다.
정작 "소부장 전문기업 확인서", "공장등록증" 같은 실제 단서는 첨부 PDF의
제출서류 표 안에 있다.

실측: PDF를 함께 읽으면 확정 탐지율이 **9% → 15%** 로 오른다.
확인한 PDF의 **절반에서 추가 단서**가 나왔다.

## 수집량 조절

```
COUNT=500 MAX_PDF=100 npm run collect
```

| 변수 | 기본값 | 뜻 |
|---|---|---|
| `COUNT` | 300 | 받아올 공고 수 (기업마당 전체는 약 1,600건) |
| `MAX_PDF` | 60 | 이번 실행에서 새로 내려받을 PDF 수 상한 |

PDF는 `pdf-cache/` 에 저장되므로 두 번째 실행부터는 새 공고만 내려받는다.
마감된 공고는 PDF를 건너뛴다.

## 확정도 읽는 법

| 표시 | 뜻 | 대응 |
|---|---|---|
| ● 확정 | 제출서류에 정식 명칭이 있음 | 바로 영업·안내 가능 |
| ◐ 가능성 | 정황 키워드 2개 이상 | 원문 훑어보고 판단 |
| ○ 검토 | 단서 1개 | 노이즈일 수 있음 |

상세 패널에 **어떤 단어를 어디서 찾았는지**가 표시된다. 오탐이면
`src/certifications.js` 의 해당 인증 `strong`/`weak` 키워드를 고치면 된다.

## 인증키

`.dev.vars` 에 `BIZINFO_KEY=...` 로 넣는다. 이 파일은 `.gitignore` 처리되어 있다.
키는 [기업마당](https://www.bizinfo.go.kr) 로그인 후 API 페이지에서 발급받는다.

## 파일 구조

```
collect.mjs              수집·분석 실행기
src/certifications.js    인증 15종 매칭 규칙  ← 정확도는 여기서 조정
public/index.html        대시보드
public/data.js           수집 결과 (자동 생성)
public/data.sample.js    예시 데이터 (수집 전 화면 확인용)
pdf-cache/               내려받은 PDF 본문 캐시
```
